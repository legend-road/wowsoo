## #1 · 伊墨苏斯

### 减伤分工

| 次序 | 内容 | 备注 |
|------|------|------|
| 1 轮 | NQ 光环掌握（虔诚） | P2 AOE① |
| 2 轮 | CJQ 光环掌握（虔诚） | P2 AOE② |
| 3 轮 | ZST 集结呐喊 | P2 AOE③ |

P1 旋涡硬顶另喊个免 / 外壳，不占上面三轮。

### 站位

**P1**
- 大团：6 点
- T：9 点
- 远程：竖排站
- 近战：一点站

**P2（10 人）**
- 预先标记 **5 根光柱**，最里面那根放掉不管
- **副T**踩圈；**主T**去里面击杀黑软
- 转阶段：**副T**第一时间嘲讽接 Boss
- 两光柱中间站人
- 4 远程分四个面
- 治疗站 **3 / 6 / 9 点**

### 起手 / 准备

- 起手嗜血
- 开怪约 10s 后：DZ 嫁祸、LR 误导 → **副T**（接小怪的 T）
- 当前 T：腐蚀冲击开个减

### 进程要点

1. 大团平行移动；放完 **3 次黑水** 后菱形集合，MS 驱散
2. DPS 看自身 debuff 层数，**超过 4 层**去清小怪；免疫不能消 DoT
3. 躲好脚下黑水与旋涡
4. P2 AOE 按 **1 / 2 / 3 轮**交全团减伤

## #2 · 堕落的守护者

### 减伤分工

常规 3 轮（一减 + 一抬）。  
每次 **灾祸** 安排一轮减伤。

### 站位 / 起手

- 起手嗜血
- 三个 Boss 起手拉在中间
- 远程：扇形分散
- 近战：Boss 身后输出

### T 注意

- **拉鲁克**：注意头朝向
- **拉何**：凿击要背身，同时躲脚下毒水

### 鲁克分身

- 当前 T：拉 **困苦化身**
- 何 T：拉 **阴郁化身** 到悔恨边上

### 职责提醒

| 职责 | 要点 |
|------|------|
| 近战 | 打背；躲脚下毒水；阴郁化身打断链 |
| 远程 | 打断孙的灼烧 |
| 治疗 | 驱散孙的暗言术：祸 |

### 击杀顺序

**鲁克 → 何 → 孙**

### 化身处理

**何化身**
- 被印记点名：开个减
- 个减快结束时传给其他人，优先 **LR / FS**
- DPS 集火击杀

**孙化身**
- 大团中间集合
- 治疗开爆发刷血
